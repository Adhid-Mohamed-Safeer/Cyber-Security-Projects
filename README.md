# 🛡️ Cyber Security Python Projects

This repository contains a collection of beginner-friendly Cyber Security projects developed using Python. These projects were created to enhance practical knowledge in cybersecurity concepts such as encryption, password security, network monitoring, and basic system security.

## 📌 Projects Included

### 1. Caesar Cipher
A Python implementation of the classical Caesar Cipher algorithm that allows users to encrypt and decrypt text messages using a user-defined shift value.

#### Features
- Encrypt plaintext messages
- Decrypt ciphertext messages
- User-defined shift key
- Preserves spaces and special characters

#### Technologies Used
- Python

---

### 2. Image Encryption Tool
A simple image encryption and decryption tool that performs pixel manipulation to secure images.

#### Features
- Encrypt images using pixel manipulation
- Decrypt encrypted images
- User-defined encryption key
- Supports common image formats

#### Technologies Used
- Python
- Pillow (PIL)

---

### 3. Password Complexity Checker
A password strength assessment tool that evaluates passwords based on multiple security criteria.

#### Features
- Checks password length
- Detects uppercase and lowercase letters
- Detects numbers and special characters
- Classifies passwords as Weak, Moderate, or Strong

#### Technologies Used
- Python
- Regular Expressions (`re`)

---

### 4. Simple Keylogger (Educational Purpose Only)
A basic keylogger developed solely for educational and ethical learning purposes. It records keystrokes and stores them in a log file.

⚠️ **Disclaimer:** This project is intended strictly for educational purposes and should only be executed on systems you own or have explicit permission to test.

#### Features
- Records keystrokes
- Saves logs to a text file
- Demonstrates keyboard event monitoring

#### Technologies Used
- Python
- pynput

---

### 5. Network Packet Analyzer
A packet sniffer that captures and analyzes network packets in real time.

⚠️ **Disclaimer:** Use this tool only on networks you own or have permission to monitor.

#### Features
- Captures network packets
- Displays source and destination IP addresses
- Identifies network protocols
- Displays packet payload information

#### Technologies Used
- Python
- Scapy
